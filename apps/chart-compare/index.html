How to compare

Feel the chart. Drag to pan, scroll to zoom, resize the window, and try each engine’s drawing and indicator tools. Use a single-chart layout for more room.

Keep the input fair. Both engines receive copies of the same OHLCV bars. Data is a fixed snapshot, not a live feed. Replay reveals existing candles; it does not simulate intrabar ticks.

Know the limits. History ends at the snapshot boundary. Shared market, interval, data and theme changes restart both charts and clear drawings. Indicators, drawings and panning are otherwise independent.
